# MAXXA AI V14 — Character Theme Gallery

## Included in source
- Added a dedicated **Character Theme Gallery** entry in the navigation drawer.
- Added all 12 requested character-inspired UI themes: Itachi, Naruto, Sasuke, Kakashi, Madara, Hinata, Sakura, Nezuko, Obito, Minato, Mitsuri and Nobara.
- Added a responsive two-column Compose gallery with accent swatches, selected-state indicator and active-theme summary.
- Persists the selected character theme in `SharedPreferences` (`character_ui_theme`).
- Applies the selected character palette to the app's Material 3 primary/secondary/tertiary colors.
- Keeps the existing 3D AI Core theme preference and Anime Voice Pack preference separate.

## Scope and verification
This is a source-level implementation. No Android build, APK generation, emulator run or physical-device test is claimed. The character cards use emoji and generated color palettes; no copyrighted anime artwork or actor voice recordings are bundled.
